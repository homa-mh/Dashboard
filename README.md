
# Building Management Dashboard

A web-based dashboard designed to simplify residential building management by providing tools for resident management, maintenance fee administration, and IoT-based building monitoring.

## Overview

Building Management Dashboard is a management interface developed to help building administrators manage residents, handle building maintenance fees, and access building-related information through a centralized platform.

The application was designed to integrate with an IoT service platform, enabling administrators to monitor building entry and exit logs and access additional after-sales services provided by the connected company.

## Features

### Resident Management
- Add and manage building residents.
- Maintain resident information through a centralized dashboard.
- Provide residents with access to relevant building services.

### Maintenance Fee Management
- Configure building maintenance fees.
- Manage maintenance fee information for residents.
- Distribute maintenance fee notifications to residents.

### Building Access Monitoring
- View building entry and exit logs.
- Access access-control information through the integrated IoT platform.
- Monitor recorded building access activities.

### IoT Service Integration
- Integration with an external IoT service platform.
- Access to building monitoring services.
- Connection to additional after-sales services provided by the IoT company.


## Application Architecture

The application was designed to work alongside an external IoT service platform.

The building management dashboard provided the administrative interface, while the external platform handled IoT-related services and building access monitoring.

**Note:** The original IoT service integration is no longer active, as access to the company's platform is currently unavailable.

## Project Scope

This repository represents the building management application developed during a professional project.

Some features depended on external company services and may no longer be operational due to the discontinued integration.
